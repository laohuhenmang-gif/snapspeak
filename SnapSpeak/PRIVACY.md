# 隐私政策

**语拍提醒 · AI助理**（以下简称"本应用"）尊重并保护用户隐私。本隐私政策说明我们如何收集、使用和保护您的信息。

## 信息收集

### 本地存储
- 所有任务数据、AI 对话记录、知识库内容均存储在设备本地 SQLite 数据库中
- 应用设置（主题偏好、AI 模型选择等）存储在设备本地

### AI 服务
- 使用 AI 功能时，您输入的文字、语音转文字内容、拍照识别的文字会发送至您选择的 AI 服务提供商（DeepSeek / OpenAI 兼容 / 自定义）
- **我们不会收集、存储或转发您的 AI 请求内容到任何第三方服务器**
- AI 请求直接由您的设备发送至您配置的 AI 服务提供商

### 相机与麦克风
- 相机权限仅用于 OCR 文字识别功能，拍照后图片可发送至 AI 服务进行分析
- 麦克风权限仅用于语音识别功能，语音实时转文字后不保留原始录音
- 我们不会通过相机或麦克风收集任何背景信息

### 通知权限
- 通知权限仅用于任务提醒，所有提醒在设备本地调度

## 信息分享

**本应用不会收集、上传或分享任何个人信息。** 所有数据仅存储在您的设备上。

## 第三方服务

- AI 功能依赖您配置的第三方服务（DeepSeek / OpenAI 兼容），请参阅对应服务商的隐私政策
- 使用 EAS Build 构建时，代码会传输至 Expo 服务器进行编译，Expo 受其自身隐私政策约束

## 数据安全

- API Key 使用系统安全存储（SecureStore）加密保存
- 可随时在设置中清除所有数据

## 联系我们

如有隐私相关问题，请通过 GitHub Issues 联系我们。
