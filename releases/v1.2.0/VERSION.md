# SnapSpeak v1.2.0

## 发布信息
- **版本号**: 1.2.0
- **发布日期**: 2026-06-14
- **基于**: v1.1.0 + P3 体验增强

## 新增功能

### 新增 4 套主题
- 森林绿（亮色/暗色）
- 海洋蓝（亮色/暗色）
- 日落橙（亮色/暗色）
- 薰衣紫（亮色/暗色）
- 共 10 套主题可选

### 消息入场动画
- 聊天消息淡入 + 上滑动画
- 使用 react-native-reanimated
- 首屏消息逐个延迟显示

### AI 多角色系统
- 小拍（🤖）：友好高效助理
- 小智（📚）：学霸型学习助手
- 小护（💚）：健康生活管家
- 教练（💪）：高效执行力教练
- 设置页可切换角色
- 角色影响 AI 语气和问候语

### 轻量数据统计
- 全部任务页顶部显示统计卡片
- 总数 / 待办 / 完成 / 逾期
- 一目了然的任务概览

## 依赖更新
- 新增 react-native-reanimated（动画支持）
- 新增 expo-document-picker（数据导入）

## 文件结构
```
app/
├── (tabs)/
│   ├── _layout.tsx      ← Tab 布局
│   ├── index.tsx        ← 今天
│   ├── all.tsx          ← 全部任务（含统计）
│   └── settings.tsx     ← 设置（含角色选择）
├── _layout.tsx          ← 根布局
└── task/[id].tsx        ← 任务详情
components/
├── AnimatedMessage.tsx  ← 动画组件（新增）
└── ...
constants/
├── personas.ts          ← AI 角色配置（新增）
├── themes.ts            ← 主题配置（扩展）
└── ...
```
