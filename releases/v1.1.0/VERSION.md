# SnapSpeak v1.1.0

## 发布信息
- **版本号**: 1.1.0
- **发布日期**: 2026-06-14
- **基于**: v1.0.0 + P2 体验优化

## 新增功能

### Tab 导航
- 三 Tab 结构：今天 / 全部 / 设置
- 底部 Tab 栏固定显示，快速切换

### 全部任务页面
- 搜索框：按标题/描述搜索
- 四种筛选：全部 / 待办 / 已完成 / 已逾期
- 点击任务进入详情
- 一键完成/删除

### 每周复盘
- 每周一自动生成上周复盘
- 统计本周计划数、完成数、完成率
- AI 生成周级建议

### 复盘操作按钮
- 复盘消息下方显示操作按钮
- [生成明日计划] / [查看详情] / [不用提醒]

### 数据导入
- 设置页新增导入按钮
- 支持 JSON 文件导入
- 导入前二次确认

### 启动时恢复提醒
- App 启动时自动恢复所有未完成任务的提醒
- 防止重启后提醒丢失

## 依赖更新
- 新增 expo-document-picker（数据导入）

## 文件结构变化
```
app/
├── (tabs)/              ← Tab 导航组（新增）
│   ├── _layout.tsx      ← Tab 布局
│   ├── index.tsx        ← 今天（原 app/index.tsx）
│   ├── all.tsx          ← 全部任务（新增）
│   └── settings.tsx     ← 设置（原 app/settings.tsx）
├── _layout.tsx          ← 根布局（更新）
└── task/[id].tsx        ← 任务详情（不变）
```
